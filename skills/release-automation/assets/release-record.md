# Release record

- **Policy.** Public compatibility promise, `0.x` breaking rule, release channel, package grouping and tag format.
- **Source.** Repository, previous tag and peeled commit, proposed head SHA, consumed commit range and merge strategy.
- **Plan.** Engine/version, config revision, generated versions/changelog/tag, dry-run command and exit code.
- **Candidate.** Disposable local path, manifest checks, package dependency changes and asset digest list.
- **Boundary.** Trigger, job permissions, environment readback, concurrency, cache absence and authority for remote writes.
- **Release.** Observed tag commit, GitHub release URL, immutable state and verification output, or not run.
- **Publication.** Separate registry state and readback, or not run.
- **Recovery.** Conflict handling, corrective-release/rollback owner, retained artifacts and operations that cannot be undone.
