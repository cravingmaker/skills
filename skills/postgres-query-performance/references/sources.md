# Sources

Read this when checking plan fields, statistics scope or index capabilities against the installed server. Instructions and parser are original; no source text or SQL is copied.

- [PostgreSQL EXPLAIN](https://www.postgresql.org/docs/current/sql-explain.html): execution effects, options and machine-readable output.
- [Using EXPLAIN](https://www.postgresql.org/docs/current/using-explain.html): row estimates, loops, buffers and plan costs.
- [pg_stat_statements](https://www.postgresql.org/docs/current/pgstatstatements.html): measured workload contribution and reset scope.
- [Cumulative statistics](https://www.postgresql.org/docs/current/monitoring-stats.html): collection and visibility limits.
- [Multicolumn indexes](https://www.postgresql.org/docs/current/indexes-multicolumn.html): ordering and version-dependent skip-scan behavior.
- [Index-only scans](https://www.postgresql.org/docs/current/indexes-index-only-scans.html), [partial indexes](https://www.postgresql.org/docs/current/indexes-partial.html) and [index types](https://www.postgresql.org/docs/current/indexes-types.html): workload-specific access paths and trade-offs.
