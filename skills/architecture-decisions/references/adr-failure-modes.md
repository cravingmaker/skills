# Decision record failure checks

Read this when auditing the argument behind a durable decision.

Check that criteria preceded the recommendation and alternatives were viable. Replace an unexplained weighted score with the decisive constraint and evidence. Require the disadvantage accepted by the choice, including operating and stakeholder costs. Keep one durable choice per record and link details that do not affect that choice.

Distinguish acceptance, implementation, and verification. Name the owner, reversal cost, confidence limits, and a condition that would justify revisiting the choice. If a record claims a guarantee, find its actual confirmation evidence. If reasoning has changed, preserve the old record and use supersession.

These checks paraphrase [Olaf Zimmermann's ADR creation guidance](https://ozimmer.ch/practices/2023/04/03/ADRCreation.html). No licensed text or template is retained.
