# Quality scenario

| Field | Project-specific value |
| --- | --- |
| Source | Actor or component causing the event |
| Stimulus | Event, failure, load, or change |
| Artifact | Component or state affected |
| Environment | Workload, resources, cache state, and failure conditions |
| Response | Required observable behavior |
| Measure | Agreed threshold or exact correctness oracle |
| Priority | Business importance and uncertainty, with reasons |
| Trade-off | Goal that becomes harder |
| Evidence | Exact command, result artifact, revision, and proof gaps |
