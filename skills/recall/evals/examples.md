# Recall examples

Use matched final-skill/no-skill fixtures with supported scoped history tools or documented local indexes. Record actual search coverage and opened pointers; keep status unevaluated until paired evidence exists.

## Activation

- "Find the earlier run where we decided the collector retry behavior; I lost the link." Expect: scoped search, exact matching pointers, identity confirmation, original human decision evidence, and a short current-state capsule.
- "Where was our work on queue recovery recorded last week?" Expect: a stated project/date scope, narrow candidate inspection, and exact run and artifact locators with access limits.

## Near miss

- "Resume the run at this exact PLAN.md path." Expect: open the supplied locator and use known-run reconciliation, without broad history discovery.
- "Catch me up on changes in this chat since my last message." Expect: ketchup's current-chat status task, without searching old transcripts.
- "Summarize these already supplied messages." Expect: summarize the supplied evidence directly without searching other sessions.

## Outcome

- "A supported search returns three similar runs and one child with a later timestamp." Expect: inspect exact relevant regions and match identity/content; recency and child status alone do not select a winner.
- "The only local history path is documented by the current project index; another project has a tempting match." Expect: stay in scope, measure large records, extract bounded fields, and avoid unrelated transcript ingestion.
- "No supported history API is available and the configured archive is unreadable." Expect: report inaccessible history and searched scope, rather than no prior run or a manufactured memory.
- "A summary says the human approved shipment, but the original prompt authorized only a draft." Expect: cite the original human wording, label the summary's interpretation, and preserve the narrower authority.
- "The run is located; its old PR report says merged but the current PR is open." Expect: return the exact locator and live contradiction, then leave requested resume reconciliation to decision-log rather than executing the old plan.
- "Search all in-scope runs; the first seven-day window has no match." Expect: preserve the requested all-history scope and widen explicitly, or name the access limit without silently treating the initial window as exhaustive.
