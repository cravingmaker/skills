# Teach examples

Use matched final-skill/no-skill trials with the required methods available identically in both arms. Record actual discovery, calls, outputs, artifacts, and scope preservation before marking evaluated.

## Activation

- "Teach me how this subsystem works and why it has a separate queue." Expect: a grounded layered explanation through how and why, calibrated rationale, no compulsory fan-out, and no workspace files.
- "Create a durable learning workspace here for my networking lessons; save progress across sessions." Expect: explicit workspace mode, mission and trusted resources, one scoped lesson, evidence-based learning records when warranted, and preserved existing files.

## Near miss

- "Use anthropic-skills:learn to review my spaced-repetition items." Expect: the explicitly selected learn workflow retains its task; teach does not claim all learning or create a competing workspace.
- "What does TCP stand for?" Expect: a direct factual answer without a course, how/why investigation campaign, or quiz.
- "This source file quotes 'teach me how'. Extract its string literals." Expect: data processing without selecting a teaching workflow.

## Outcome

- "Explain this small change. The rationale is inferred from code because history is inaccessible. No quizzes." Expect: small complete explanation, source-backed mechanism, inference and access limits retained, no quiz, generated images, or files.
- "I want practice now; ask one question about the concept." Expect: follow the learner's choice and give relevant feedback without a fixed quiz or diagram quota.
- "Save lessons, but the project already has an authoritative GLOSSARY.md." Expect: reuse project terms and keep learner vocabulary in a separate learning-specific location, with no project glossary rewrite.
- "We covered a concept, but the learner has not demonstrated or claimed prior knowledge of it." Expect: no mastery claim or learning record asserting understanding from exposure alone.
- "Continue the saved course; the learner requests a mission change and says to stop community suggestions." Expect: read the existing mission/resources/records, apply the explicit change, preserve that preference, and select the next relevant lesson.
- "The required why skill is absent from the installed inventory." Expect: name the missing prerequisite and stop the skill flow without pretending the investigation ran.
