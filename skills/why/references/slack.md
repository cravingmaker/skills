# Chat history

Read this when relevant deliberation may exist only in conversation. Slack is one example; use the available supported chat source.

Inspect the current tool's search and thread capabilities. Start with a relevant author, date window, PR URL, ticket ID, domain term, or exact error string. Fetch the complete relevant thread before attributing a decision to one message.

Keep the original speaker, date, permalink, and enough wording to establish scope when a human ruling matters. Jokes, tentative proposals, quoted commands, and copied agent interpretations are not new decisions.

Retention limits, private messages, access errors, and missing authentication restrict coverage. Report them without inventing results or exposing credentials. A search returning no matching accessible message does not establish that a conversation never happened.

Return only relevant excerpts, context, and the actual search scope. Investigation reads chat; it does not send a message or ask an author on the user's behalf.
