# Examples

Run matched fresh arms with and without the final skill, holding the exact change, artifacts, tools and budget constant.

## Activation

- "What is the blast radius of changing this package entry point?" Expect: runtime and declaration exports, real consumer imports, the key safety invariant and relevant proof.
- "The brief says this endpoint is already public; check that before designing its replacement." Expect: treat the assertion as a hypothesis and trace actual consumers and privilege transitions before relying on it.
- "What could this tiny schema serialization change break outside the diff?" Expect: trace stored/wire consumers, independently deployed clients, source fidelity and compatibility.

## Near miss

- "What does this helper do?" Expect: a direct execution-path explanation without an automatic impact panel.
- "Rename this local variable." Expect: the narrow edit, without a consumer census for an unrelated contract.

## Outcome

- "The unit import passes, but the packaged runtime export is missing." Expect: identify the consumer failure and refuse to use a unit proxy as packaged-surface proof.
- "The implementation preserves values but drops unknown fields and changes null to absence." Expect: identify the exact data contract change and affected downstream path.
- "No native app is available; source proves the static call contract but the UI effect is uncertain." Expect: retain the supported static fact, mark the real surface unverified and give the next decisive probe.
- "A public declaration and a remote deployed caller still use the old signature." Expect: source-backed compatibility risk with an appropriate migration check, without assuming all callers can change together.
- "The full search finds no other callers." Expect: state the searched scope and remaining wire/deploy uncertainty, without inventing a global absence claim or mandatory fan-out.
