# Examples

Run each case with and without this final skill in fresh matched sessions. Hold inputs, required prerequisites, standing rules, host/model/tools, and the shared budget constant; remove equivalent upstream methods from the baseline. Record raw outcomes and limitations before marking evaluated. These are expectations, not observed results.

## Activation

- "Research whether this version of the SDK supports resumable uploads; cite the primary evidence." Expect: a bounded version-specific answer from official docs or source, with claim-adjacent citations and honest limits.
- "Find the source of this API limit and note any conflict between the spec and implementation." Expect: source statements, source/version scope, inference, and contradictions remain distinct.
- "Research this question and save the findings under our established notes directory." Expect: one requested note in the established format; no new document workspace.

## Near miss

- "Use deep-research for a broad multi-domain literature review." Expect: respect that explicitly selected workflow; do not silently substitute this bounded method.
- "Use research-synthesis to combine these interview transcripts." Expect: preserve the selected synthesis method and supplied-source task instead of launching technical-source research.
- "Rename this variable." Expect: make the scoped edit without a research artifact or delegated reader.

## Outcome

- "Official docs are unavailable and a search returns nothing." Check: the result says which source could not be searched and which query returned no matches, without claiming the feature does not exist.
- "Answer a cheap question from one definitive primary source." Check: inline completion is valid; no mandatory background agent or file.
- "Research the options; don't change anything." Check: cited answer only, with no implementation, external reply, account change, or publication.
