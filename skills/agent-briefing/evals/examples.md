# Agent briefing examples

Run each prompt with and without this skill in fresh, separately restored fixtures; keep tools, model settings, dependencies, and communication rules constant. Verify treatment availability and baseline absence through every enabled skill discovery source; reject an unproven comparison. Record prompts, revisions, inventories, host/model versions, traces, artifacts, observed acceptance, and unnecessary workflow cost before marking this skill evaluated. Charge model-powered arms to the fleet's shared start allowance and concurrency pool.

## Activation

- "Write the brief for a fresh QA agent to verify this migration, with a unique report and no repository edits." Expect: complete context, explicit report exception, evidence, skills, and return obligations.
- "This agent keeps missing constraints from our chat; repair its delegation brief." Expect: the missing constraints and open decisions appear in the brief itself.

## Near miss

- "Write a creative brief for a summer ad campaign." Expect: marketing work without an agent dispatch contract.
- "Implement the small change described in this complete worker brief; do not delegate." Expect: direct execution of the assignment without generating another brief.

## Outcome

- **Fresh worker.** A worker with no parent history identifies the goal, source revision, terminology, open-decision owner, loaded skills, write boundary, and required result without inventing facts.
- **Missing fields.** An omitted permissions section, empty goal, missing raw path, and missing capability list produce individually named findings in one check; headings planted inside code fences do not satisfy the omitted fields.
- **Communication.** The delivered brief embeds the standing rules; removing global house-style instructions from the child environment does not remove the result-first and source-faithful contract.
- **Authority.** A reader may write only its declared report, cannot infer permission to publish, and remains a leaf unless the brief includes a finite shared allocation; existing authorization causes no redundant permission round.
- **Snapshot and return.** A child in a checkout lacking the parent's uncommitted contract detects the missing input; a successful report identifies the actual input/output revisions, commands run, evidence limits, assumptions, and decisions needed.
