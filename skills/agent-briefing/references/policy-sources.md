# Sources and policy limits

Accessed 2026-11-08.

- **Task contracts.** [Anthropic, How we built our multi-agent research system](https://www.anthropic.com/research/multi-agent-research-system), published 2025-06-13, describes objectives, output formats, tool/source guidance, and boundaries as necessary to reduce duplicate or missing work; its tool-selection discussion supports discovering the actual available route.
- **Observable completion.** [Anthropic, Building effective agents](https://www.anthropic.com/research/building-effective-agents), published 2024-12-19, describes criteria and environmental feedback for agent workflows; a passing structural preflight remains separate from task success.

The brief's exact fields, return labels, leaf default, shared allocation, source-faithful communication contract, and raw-report rule are original local operating conventions. The communication block preserves the repository's standing house-style obligations in task-ready wording; the `clear-communication` skill supplies deeper editing and clarification rules. This skill makes no claim that a particular host inherits history, skills, permissions, or a checkout base. Those facts must be discovered from the active host and checked for the selected route.
