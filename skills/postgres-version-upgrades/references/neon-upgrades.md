# Neon upgrades

Read this when source or destination is a managed Neon database. Check the current [Neon documentation](https://neon.com/docs/) and installed provider tooling for supported minor maintenance and major transitions, release eligibility, extension versions and project/branch scope. Treat experimental assessment tools as assessment only until their current support and intended use are confirmed.

Record source/destination account, project, region, branch, endpoint, actual engine version, connection mode, roles and external service dependencies. Determine live whether the selected version transition is supported within existing resources or requires a separate destination; never assume a branch can change its parent's engine major. Use the current supported provider workflow or documented migration method; host package managers, filesystem copying and pg_upgrade against provider storage are outside this adapter.

Rehearse with synthetic data in an explicitly disposable destination whose identity is independently verified. If a new project/endpoint is required, inventory databases, roles, grants, extensions, jobs, subscriptions, connection pools and any dependent Functions or object resources; prove what is copied and what needs separate handling. Choose direct or pooled connections according to the supported operation and verify the mode through provider inventory; a hostname pattern alone is not proof.

Record maintenance/reconnect behavior and measured application outage; a successful provider operation does not establish driver, access, sequence or query compatibility. Bind recovery evidence to the correct history/project/branch and verify its current eligibility and scope rather than assuming the source fallback includes new writes. Prepare exact routing/connection updates and a single-writer fence before cutover; actual traffic or production provider changes need the task's explicit authorization. Return provider-supported method, identity evidence, rehearsal, post-version application checks and remaining limits; do not quote plan limits or prices from memory.
