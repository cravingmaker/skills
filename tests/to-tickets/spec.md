## Problem Statement

Shoppers repeat the same searches and lose them between visits.

## User Stories

1. As a shopper, I want to save a search with a name, so that I can find it again
2. As a shopper, I want an empty name rejected, so that every saved search is findable
3. As a shopper, I want to see my saved searches, so that I can pick one
4. As a shopper, I want to rerun a saved search, so that I get current results
