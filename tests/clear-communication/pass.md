# Validate the repository

Run `./scripts/validate.sh` to check every skill. It exits with code 1 when a rule fails.

The checker reads the original frontmatter — an em dash is allowed by default.

> I hope this helps. In order to quote a source, keep its exact words.

```sh
# Code stays as written: in order to, utilize, “curly”.
echo "I hope this helps"
```

See the [Vale docs](https://vale.sh/docs/in-order-to) for configuration.
